# Haze Sync Agentic Control Plane

This directory is the operational control plane for agentic development.

- Protocol version: 4
- Control branch: `agentic/orchestration`
- Product branches: `component/*`
- Canonical component list: `docs/process/component-index.md` on `main`

Active prompts, reports, executions, chat registrations, and archives are created on demand. Product code and component documentation remain outside this branch.

Legacy component-local `control/` folders are not authoritative for protocol v4 and are intentionally left unchanged until final cleanup.
